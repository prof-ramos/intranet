# Testes E2E Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add end-to-end tests with Playwright covering authentication, role-based access control, core user journeys (dashboard, associates, juridico), and CSV report download.

**Architecture:** Playwright runs against a local Next.js dev server. A dedicated test database (`asof_test`) is seeded with a known admin user before each test file. Tests authenticate via a login fixture that performs a real form submission, producing a valid JWT cookie. Role tests reuse the same seed data with different user roles.

**Tech Stack:** Playwright, Next.js 16, Drizzle ORM, PostgreSQL, Vitest (unit), `tsx` (seed scripts)

---

## File Structure

| File | Responsibility |
|---|---|
| `playwright.config.ts` | Playwright runner config: baseURL, workers, retries, projects (chromium), globalSetup |
| `e2e/global-setup.ts` | Start dev server, ensure test DB exists, run migrations, seed admin user |
| `e2e/global-teardown.ts` | Stop dev server, optionally drop test DB tables |
| `e2e/fixtures.ts` | Custom `test` fixture with `loginAsAdmin`, `loginAsSecretaria`, `loginAsDiretoria` helpers |
| `e2e/auth/login.spec.ts` | Login success, failure, rate limiting, redirect after auth |
| `e2e/auth/roles.spec.ts` | Access denied for `secretaria` to juridico, allowed for `admin`/`diretoria` |
| `e2e/app/dashboard.spec.ts` | Dashboard loads, indicators render, sidebar navigation works |
| `e2e/app/associados.spec.ts` | Search, pagination, profile page, CSV download |
| `e2e/app/juridico.spec.ts` | Create consultation, update status, add note, view detail |
| `e2e/helpers/db.ts` | Drizzle client pointing to `asof_test`, truncate helpers |
| `scripts/seed-e2e.ts` | Seed one admin, one diretoria, one secretaria, and a few associates for E2E |

- [ ] **Step 5: Create global setup**

Create `e2e/global-setup.ts`:

```ts
import { execSync, spawn } from 'child_process';
import path from 'path';

const TEST_DATABASE_URL =
  process.env.TEST_DATABASE_URL ?? 'postgres://postgres:postgres@localhost:5432/asof_test';

export default async function globalSetup() {
  // Ensure test DB exists
  try {
    execSync(`createdb asof_test`, { stdio: 'ignore' });
  } catch {
    // DB may already exist
  }

  // Run migrations
  execSync(`DATABASE_URL="${TEST_DATABASE_URL}" npx drizzle-kit migrate`, {
    cwd: path.resolve(process.cwd()),
    stdio: 'inherit',
  });

  // Seed E2E data
  execSync(`TEST_DATABASE_URL="${TEST_DATABASE_URL}" npx tsx scripts/seed-e2e.ts`, {
    stdio: 'inherit',
  });

  // Start dev server
  const devServer = spawn('npm', ['run', 'dev'], {
    cwd: process.cwd(),
    env: {
      ...process.env,
      DATABASE_URL: TEST_DATABASE_URL,
      SESSION_SECRET: 'e2e-session-secret-at-least-32-characters-long',
      PORT: '3001',
    },
    stdio: 'pipe',
    shell: true,
  });

  // Wait for server ready
  await new Promise<void>((resolve, reject) => {
    const timeout = setTimeout(() => reject(new Error('Dev server failed to start')), 30000);
    const onData = (data: Buffer) => {
      const text = data.toString();
      if (text.includes('Ready in') || text.includes('localhost:3001')) {
        clearTimeout(timeout);
        devServer.stdout?.off('data', onData);
        resolve();
      }
    };
    devServer.stdout?.on('data', onData);
    devServer.stderr?.on('data', (data) => {
      if (data.toString().includes('error')) {
        console.error(data.toString());
      }
    });
  });

  // Store server ref for teardown
  (globalThis as unknown as Record<string, unknown>).__DEV_SERVER__ = devServer;
}
```

- [ ] **Step 6: Create global teardown**

Create `e2e/global-teardown.ts`:

```ts
export default async function globalTeardown() {
  const devServer = (globalThis as unknown as Record<string, unknown>).__DEV_SERVER__ as
    | import('child_process').ChildProcess
    | undefined;

  if (devServer) {
    devServer.kill('SIGTERM');
    await new Promise((resolve) => setTimeout(resolve, 2000));
    if (!devServer.killed) {
      devServer.kill('SIGKILL');
    }
  }
}
```

```ts
import { test as base, expect } from '@playwright/test';

export type UserRole = 'admin' | 'diretoria' | 'secretaria';

interface Fixtures {
  loginAs: (role: UserRole) => Promise<void>;
}

export const test = base.extend<Fixtures>({
  loginAs: async ({ page }, use) => {
    const credentials: Record<UserRole, { email: string; password: string }> = {
      admin: { email: 'e2e-admin@asof.local', password: 'Senha-Forte-2026!' },
      diretoria: { email: 'e2e-diretoria@asof.local', password: 'Senha-Forte-2026!' },
      secretaria: { email: 'e2e-secretaria@asof.local', password: 'Senha-Forte-2026!' },
    };

    const loginFn = async (role: UserRole) => {
      const creds = credentials[role];
      await page.goto('/login');
      await page.fill('input[name="email"]', creds.email);
      await page.fill('input[name="password"]', creds.password);
      await page.click('button[type="submit"]');
      await page.waitForURL('/app');
    };

    await use(loginFn);
  },
});

export { expect };
```
